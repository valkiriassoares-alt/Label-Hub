🚀 Label HUB

🎮 Um hub simples e leve para Roblox, criado para reunir diferentes ferramentas de jogador em uma única interface.

✨ O Label HUB possui uma interface organizada e fácil de utilizar.

🧩 O projeto conta atualmente com diferentes funções para personalização e movimentação do personagem.

👤 PLAYER

🚶 WalkSpeed

⚡ Permite alterar a velocidade de caminhada do personagem.

🔢 O valor pode ser definido através da caixa de texto.

📈 Limite máximo: 750.

🦘 JumpPower

💨 Permite alterar a força do pulo do personagem.

🔢 O valor pode ser definido diretamente pela interface.

📈 Limite máximo: 250.

✈️ Fly

🪽 Sistema de voo integrado ao hub.

🔘 O Fly pode ser ativado ou desativado pelo botão da interface.

🎮 Controles:

⬆️ W — Frente

⬇️ S — Trás

⬅️ A — Esquerda

➡️ D — Direita

⬆️ Space — Subir

⬇️ Ctrl — Descer

🎥 O movimento acompanha a direção da câmera.

📍 TP Tool

🛠️ O hub possui uma ferramenta de teleporte.

🎯 Após equipar a ferramenta, o jogador pode clicar em uma posição do mapa.

📌 O personagem será movido para a posição selecionada.

♻️ O sistema evita criar várias ferramentas iguais desnecessariamente.
